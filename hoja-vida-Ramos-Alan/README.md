## Descripción del proyecto

Este proyecto consiste en el desarrollo de una hoja de vida personal
utilizando HTML5.

La página presenta información personal, formación académica,
experiencia académica, habilidades, cursos, idiomas, proyectos
y un formulario de contacto.

El objetivo principal del proyecto es poner en práctica el uso
de diferentes etiquetas HTML5 y aprender a crear una página web
estructurada y accesible.
